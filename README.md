### Description

**ROMSorter** is a simple but powerful script to **automatically organize your thousands of Nintendo DS ROMs** into the right categories. (twilight menu++) No more sorting through endless folders — **let the script do the work for you!**

This script categorizes your ROMs based on popular game franchises, including Pokémon, Mario, Sonic, Mega Man, and many more. All it takes is a click to neatly sort your entire collection!

### Features
- Automatically sorts your Nintendo DS ROMs into predefined game franchise categories.
- Handles thousands of ROM files with ease.
- Easily extendable with additional categories and keywords.
- A simple, one-click solution to keep your collection organized.
  
### How It Works

1. Place your `.nds` files in the folder with the script.
2. Run the script to categorize your ROMs into respective folders such as "Pokemon," "Mario," "MegaMan," and more.
3. Any unrecognized ROMs are automatically placed in an "Unsorted" folder for you to handle later.

### Requirements

- **PowerShell** for Windows (Script runs on PowerShell).
- Your ROMs should be in `.nds` format for proper sorting.
